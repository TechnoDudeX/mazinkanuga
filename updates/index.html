8. 🎯 The email build method — the craft handover

The most valuable thing in the whole handover, and it exists nowhere else. Write it up as a team SOP before Aug 14.

Why not the drag-and-drop builder

"Because this way you have more control on the rendering… drag-and-drop is gonna take you 10x the time. This will save you an hour, really."

The method

  1. Clone the previous send in HubSpot. Update the email title. The list stays the same. Exclude opt-outs; send to the engaged segment.
  2. ⚠️ Create a NEW template every time — never overwrite the old one. "You want to maintain the archive of all the past [sends]." Then paste the previous template's HTML into the new one.
  3. Open the previous email → Edit → select all → copy the raw HTML.
  4. Paste that HTML into Claude, together with the new copy and every link listed out separately, and ask it to rebuild the template.
  5. Paste the returned HTML back into the new template. Preview, test, send.
  6. Images: host them by dragging into HubSpot, then use the hosted link.

🔴 The trap that silently breaks every send

"All the outbound URLs — they will embed the URL. So when you copy a link, you don't want to copy over the [wrapped] URL."

Chainlink wraps outbound URLs. Copy link text out of a Google Doc and you get the wrapper, not the destination.

✅ The fix: click the link, let it open, copy the clean URL from the browser address bar. Hand clean URLs to the AI alongside the copy. Put this in every send checklist.
